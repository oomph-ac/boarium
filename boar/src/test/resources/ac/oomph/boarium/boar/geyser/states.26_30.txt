# Each line: the Bedrock block name, which of its states Geyser maps a Java state to (* for all, else 0 or 1 per state in palette order), then the facts of its mapped states, once when they are all the same, else once per mapped state.
# A fact is three flags of the Java state (s face sturdy, r replaceable, w waterlogged, . for none), then whether an oak fence, and then a glass pane, joins the state when the state is north, east, south or west of the fence, in that order (1 joins).
# Blocks that no Java state maps to are left out. Names are without minecraft:.
# When the Bedrock palette changes, these facts no longer hold: rebuild them from the Geyser build of that version, or drop the tests that read them.
